# Повідомлення й попапи

- `Popup.tsx` — модальний контейнер: blur фону через PopupBackground, затемнення, safe area, прокручування, клавіатура, Android Back і Reduce Motion. Вміст та закриття передає екран. Натискання на фон не закриває форму випадково.
- `MessageCard.tsx` — заголовок, опис, іконка, основна й додаткова дія. `tone="glass"` — синій стиль попапів; `tone="warning"` — тепла картка зі «13 · Stany wspólne». Можна використовувати без попапа для звичайних повідомлень. Помилки завантаження QueryState показує тільки в Popup; закриття не прибирає поточний контент.
- `../forms/FormCard.tsx` та `FormInput.tsx` — контейнер і компактні темні поля зі стилю «Popup / Document form». FormInput перевикористовує Input, включно з фокусом та помилками.

Figma: `12 · Popapy i komunikaty` (288:19823), `Popup / Document form` (280:5035), `13 · Stany wspólne` (288:19824).

`components/profile/CompleteProfileAlert.tsx` складає повідомлення про основні дані. ProfileGuard показує його перед створенням документа; NewDocument також обробляє неповні дані після оновлення профілю або відповіді API. Перехід до `/profile/edit` виконується тільки дією «Заповнити». Скасування повертає назад. Усі тексти — у чотирьох мовних файлах.

`TabScrollView` додає pull-to-refresh тільки у вкладках і оновлює активні TanStack queries за queryRoots поточної сторінки. DetailScreen не змінено.

`ProfileAvatar` відкриває системну галерею, обрізання, перетворює вибране зображення у JPEG до 1024 px і завантажує через account/me/avatar. Скасування галереї нічого не змінює.

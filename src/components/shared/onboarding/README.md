# Спільні компоненти онбордингу

- `OnboardingPager`: горизонтальний свайп, керований `index`, довільний вміст через `renderPage`. Кожен крок має вертикальну прокрутку для вузьких/невисоких екранів і довгих перекладів. Сусідні кроки приховані від screen reader; зміна ширини зберігає поточний крок.
- `OnboardingProgress`: індикатор кроку з доступним текстовим описом.
- `../animation/Floating`: ледь помітний рух через native Animated, без нових залежностей. `active` вимикає рух на неактивних сторінках. Пауза у фоні та при Reduce Motion.

Компоненти не знають про API, мови, сесію чи збереження проходження. Конкретний сценарій лежить у `components/onboarding/first`.

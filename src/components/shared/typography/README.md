# Текст застосунку

`Text` і `TextInput` — тонкі обгортки React Native з фіксованим розміром тексту (`allowFontScaling={false}`, `maxFontSizeMultiplier={1}`). Це погоджене продуктове рішення; системний розмір шрифту не змінює наш UI.

У всіх нових компонентах імпортувати їх звідси, а не з `react-native`. Стилі, accessibility props, події та ref передаються як звичайно. Розміри задаються стилями кожного компонента. Нативна клавіатура, системні діалоги та інтерфейс Expo Go належать операційній системі й не підпадають під це правило.

# FadeSwap

Спільна анімація заміни контенту, без залежності від авторизації чи Router.

```tsx
<FadeSwap value={mode} duration={120}>
    {(visibleMode) => visibleMode === 'login' ? <LoginForm /> : <RegisterForm />}
</FadeSwap>
```

`value` — рядковий ключ контенту; children отримує ключ, який зараз показується. Стара форма зникає за duration мс, замінюється, нова з’являється за duration мс. Висота природна, не анімується. Змонтована лише одна форма; її локальний стан скидається при заміні. Однаковий ключ не запускає повторний fade.

Opacity працює через Animated із useNativeDriver. При Reduce Motion заміна миттєва. Нова зміна ключа скасовує попередню анімацію; після unmount callback не змінює стан. Під час зникнення контент не приймає торкання.

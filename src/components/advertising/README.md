# Реклама

- `SmallBannerCard.tsx` — малий банер: синя картка, текст ліворуч, фото справа біля нижнього краю. Пропорції фото збережені; прозорі поля всередині самого файлу не обрізаються.
- `BigBannerCard.tsx` — великий банер 370:500, фото cover, компанія з логотипом, заблюрений футер. Android 12+ використовує BlurTargetView; старі Android і Reduce Transparency мають затемнену підкладку.
- `BannerSlider.tsx` — горизонтальний свайп, сторінки на ширину контейнера, спільні `shared/pagination/PaginationDots`. Одна реклама показується без дотів. Без автопрокрутки.
- `PartnerAds.tsx` — готовий блок для сторінки: TanStack Query, слайдер і великий банер. Приймає `offset` та `viewportHeight` видимої частини батьківського ScrollView для обліку показів. Блок повинен бути безпосереднім дочірнім елементом contentContainer, щоб його `onLayout.y` мав ту саму систему координат.
- `banner-content.ts` — вибір PL/UA/EN/RU, польський fallback, перевірка HTTP(S) посилання та видимості.

Підключено в `components/legalization/LegalizationPage.tsx`, під привітанням у всіх трьох секціях. Компоненти не залежать від текстів або ID ATLANTIS.

API: `random/small`, `random/big`. Активність реклами, компанії, дати й ліміти перевіряє бек. Реклама та її опубліковані зображення доступні всім залогованим акаунтам без підписки. При відсутності реклам або помилці запиту блок приховується, під час завантаження — спільний Skeleton. Повторне відкриття вкладки/повернення у застосунок може оновити прострочений кеш (60 секунд).

Показ надсилається після секунди видимості щонайменше половини картки, тільки на активному екрані та в активному застосунку. Один ID рахується один раз за монтування блока; приховані слайди не рахуються. Клік відкриває посилання, потім надсилає статистику. Помилка статистики не блокує перехід.

Фото завантажує `shared/media/PrivateImage.tsx`: bearer у заголовку, розмір small/medium/large, кеш TanStack окремий для кожного акаунта. Токени не потрапляють у URL.

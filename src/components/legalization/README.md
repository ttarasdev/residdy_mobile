# Легалізація

`LegalizationPage.tsx` — хедер, скляний перемикач і спільний вступний блок трьох секцій (`LegalizationIntro.tsx`).
Вибір зберігається у параметрі маршруту `section`: `cases` (за замовчуванням), `documents`, `consultations`.
Невідоме значення показує кейси. `router.setParams` перемикає секцію без нового екрана в історії.

Спільний `../shared/segmented-control/GlassSegmentedControl.tsx` отримує `items`, `value`, `onChange`, `blurTarget` і не залежить від роутера.
Перемикач накладений поверх області скролу: майбутній контент проходитиме під склом.
На Android джерело розмиття — `BlurTargetView` лише з контентом, без самого перемикача.
При Reduce Motion анімації вимкнені; при Reduce Transparency скло замінюється непрозорою поверхнею.

Секції підключені до API. Консультації показують майбутні записи та популярні/всі теми; кнопка вступу відкриває consultations/mine. Тема веде на тижневий розклад, далі — бронювання та керування записом на окремих сторінках.

Польські заголовки та підписи взяті зі збереженої структури Figma: Sprawy `278:3337`, Dokumenty `280:4480`, Konsultacje `280:4099`. Є переклади українською, англійською та російською. Використовуємо наявний `Button`: компактна напівпрозора кнопка висотою 40, заголовок Manrope SemiBold.

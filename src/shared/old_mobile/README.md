# Старий Residdy — довідковий архів

Цей проєкт збережено для перенесення функцій у новий застосунок.
Вихідний код закоментований рядок за рядком; оригінальний текст збережений.
Фото, зображення, інші ресурси та конфігурації залишені для довідки.

Видалено згенеровані файли та локальні середовища: `ios/build`, `ios/Pods`,
`.expo`, `.venv`. Архів виключений із перевірки TypeScript нового проєкту.
Не запускайте команди встановлення або збірки в цій папці.

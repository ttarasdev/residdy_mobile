# Реклама при відкритті

API-клієнт без UI, Firebase та push. Працює після входу User, навіть без чинної підписки.

```ts
const { announcement } = await appAnnouncementsApi.getActive({
  baseUrl: 'http://192.168.1.10:3000',
  token: accessToken,
  lan: 'UA',
  signal: controller.signal,
})
```

`announcement: null` означає відсутність активної реклами. Мову можна не передавати: сервер використає мову профілю. `imageUrl` — публічний шлях; додай origin API, а не адресу Metro. Одна картинка може використовуватися для всіх мов.

Коли з'явиться UI: запитувати при відкритті після авторизації, скасовувати запит при виході, не блокувати запуск при помилці. Перевіряти `endsAt` перед показом. Зберігати локально дату фактичного показу за ID оголошення; максимум один показ цього оголошення за календарний день пристрою. Відмічати після показу, а не після запиту. Закриття завжди доступне.

Без `action` картинка не клікабельна. `external_url` відкриває HTTPS-сайт; `screen` містить ключ екрана; інші типи містять ID запису. Навігацію реалізує майбутній UI; завантаження запису використовує звичайний API із перевіркою доступу. `consultation` — ID послуги specialist-consultation, не бронювання. `case` — ID каталожного кейса, не особистого user-case. Недоступна ціль має показувати зрозумілий стан, а не обходити доступи.

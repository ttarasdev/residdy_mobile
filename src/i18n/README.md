# Мови застосунку

- Чотири словники: `messages/pl.json`, `uk.json`, `en.json`, `ru.json`.
- `DEFAULT_LANGUAGE = pl` в `index.ts` — початкова мова всього застосунку та fallback. Не визначаємо мову за налаштуваннями телефона.
- Явний вибір зберігається в AsyncStorage (`residdy.language`) та має пріоритет після перезапуску.
- Компонент `components/shared/language/LanguageSwitcher.tsx` перемикає глобальну мову через `setLanguage`. Не створювати окремий стан мови для сторінок.
- Усі нові UI-написи додавати одразу до чотирьох словників і читати через `useTranslation`. Серверний контент перекладається на стороні його джерела.
- Під час реєстрації поточна мова передається серверу як PL / UA / EN / RU.
